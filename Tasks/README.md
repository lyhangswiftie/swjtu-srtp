# SecureCodeAct 任务卡目录

本目录包含 **SecureCodeAct** 项目的所有开发任务卡（Task Cards）。任务卡按优先级分组，采用 Markdown 格式记录，便于团队协作与进度追踪。

---

## 目录结构

```
Tasks/
├── README.md                    ← 本文件（任务总览）
├── P0-Foundation/               ← P0：基础建设（最高优先级）
├── P1-Security-Core/            ← P1：安全核心功能
├── P2-Dashboard/                ← P2：安全分析仪表盘
├── P3-Integration/              ← P3：外部集成与工具链
└── P4-Advanced/                 ← P4：高级功能与研究性任务
```

---

## 优先级说明

| 优先级 | 分组 | 说明 |
|--------|------|------|
| **P0** | Foundation | 项目基础建设，包括环境搭建、基线验证、CI/CD 配置等，是后续所有开发的前提 |
| **P1** | Security Core | 核心安全功能，包括漏洞检测引擎、自动修复模块、运行时验证等 |
| **P2** | Dashboard | 安全分析仪表盘，包括前端 UI 改造、Security Dashboard、可视化报告等 |
| **P3** | Integration | 外部工具集成，包括 SAST/DAST 工具接入、CI/CD 流水线集成、IDE 插件等 |
| **P4** | Advanced | 高级功能与研究性任务，包括多 Agent 协同、漏洞知识库、自动化渗透测试等 |

---
