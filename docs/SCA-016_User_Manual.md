## 1 绪论

### 1.1 研究背景

SecureCodeAct (SCA) 是一款面向已知漏洞（CVE）自动化分析与修复的智能平台。本手册旨在指导安全分析师（Security Analyst）及开发人员快速掌握平台使用方法。

### 1.2 研究内容

本文档涵盖了 SCA 平台的核心功能、UI 界面说明及典型漏洞（如 CVE-2024-22120）的端到端分析流程。

### 1.3 技术突破点

- **自动化端到端分析**：集成漏洞定位、PoC 验证、Patch 生成及验证。
- **实时联动视图**：SCA-HUD 界面支持毫秒级状态同步。

## 二、 技术方案正文

### 2.1 UI 界面说明

SCA-HUD 采用 3 列布局设计，主要功能区域如下：

(1) **任务交互端（Chat）**：位于左侧上方。用户在此输入自然语言指令（例如：“分析 CVE-2024-22120”）。
(2) **漏洞列表（Vuln List）**：位于左侧下方。实时显示漏洞状态（如“未修复”、“已修复”）。
(3) **代码属性图（CPG）**：位于中间上方。可视化展示代码抽象语法树（AST）、控制流（CFG）、污点传播（Taint）及执行点（Sink）。
(4) **代码修复（Diff）**：位于中间标签页。展示漏洞修复前后的代码对比。
(5) **系统日志（SystemLog）**：位于中间下方。显示实时分析日志。
(6) **沙箱终端（Terminal）**：位于右侧上方。显示智能体（Agent）执行的底层命令及输出。
(7) **MVP 操作面板**：位于右侧下方。提供“生成 POC 利用代码”、“执行根因分析”、“生成修复 Patch”、“应用补丁”等快捷操作。

### 2.2 典型使用流程

以分析 CVE-2024-22120 为例，执行以下步骤：

(1) **启动分析**：在左侧 Chat 框输入分析指令，点击发送。
(2) **查看图谱**：系统自动生成 CPG 图谱，定位 SQL 注入点（`audit.c:182`）。
(3) **验证漏洞**：点击右侧“生成 POC 利用代码”按钮，Agent 自动执行时间盲注验证（SLEEP 5s）。
(4) **生成补丁**：点击右侧“生成修复 Patch”按钮，查看中间 Diff 视图，确认 `value_esc` 替换方案。
(5) **应用补丁**：点击“应用补丁”按钮，左侧 Vuln List 状态实时更新为“已修复”。

## 三、 项目研究结论及展望

### 3.1 研究结论

本手册详细介绍了 SCA 平台的使用方法及界面布局，通过 5 步端到端流程，用户可快速完成漏洞分析闭环。

### 3.2 创新成果

SCA 平台显著降低了漏洞分析的技术门槛，提升了安全修复的自动化水平。

### 3.3 下一步研究展望

未来将增加批量 CVE 自动化扫描及修复功能，并支持更多编程语言（如 Java、Go）。

## 四、 附录：实践报告（安装与使用操作步骤）

### 4.1 安装步骤

(1) 确保系统已安装 Docker 引擎（版本 20.10+）。
(2) 获取 GitHub 仓库访问权限。
(3) 运行一键安装脚本：
   ```bash
   git clone https://github.com/SWJTU-AI-Lab/securecodeact.git
   cd securecodeact
   export OPENAI_API_KEY="your-api-key"
   bash install.sh
   ```
(4) 脚本执行完成后，SCA-HUD 服务将在本地 `3000` 端口启动。

### 4.2 访问与使用

(1) 打开浏览器，访问 `http://localhost:3000`。
(2) 确认界面呈现 3 列布局（非 OpenHands 默认界面）。
(3) 参照 2.2 节“典型使用流程”开始漏洞分析。
